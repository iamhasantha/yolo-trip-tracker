YOLO / 100-SECOND FILM / UI SOURCE FOOTAGE

Recorded from the actual Vue application using a separate demo database.
All names, PINs, messages and transactions are fictional demo data.
Delivery: H.264 MP4, 1920x1080, 30 fps, silent, plus PNG stills.
Chrome records changed frames; static holds are intentionally duplicated
at export. No music, voiceover, titles or synthetic product UI are baked in.

SOURCE AND REPRODUCTION
capture.mjs controls a dedicated Chrome recording instance on port 9224.
It requires the app on port 4100 with a disposable database, plus a built
frontend. Running it creates a new demo trip and completes that trip.
encode.py encodes captured JPEG frame sequences with FFmpeg and Pillow.
The original temporary demo database is /tmp/yolo-video-demo.sqlite.
The working frame sequences are retained in work/ outside the ZIP.
No application source files were modified.
